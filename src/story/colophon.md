This site is set in [![](/tool-icons/cal.png)Cal Sans](https://github.com/calcom/font) and built with [![](/tool-icons/astro.svg)Astro](https://astro.build) and [![](/tool-icons/tailwind.png)Tailwind CSS](https://tailwindcss.com). It's hosted on [![](/tool-icons/cloudflare.png)Cloudflare Workers](https://workers.cloudflare.com).

Notes are markdown files in a GitHub repo. I write them in an editor I built into the site, and publishing one opens a pull request. Reactions are stored in [![](/tool-icons/convex.png)Convex](https://convex.dev), search runs on [![](/tool-icons/fuse.png)Fuse.js](https://www.fusejs.io), and [![](/tool-icons/umami.png)Umami](https://umami.is) counts visits.

I started the site in July 2025 and moved it from Netlify to Cloudflare in July 2026. About half the commits since January were made with [![](/tool-icons/claude.png)Claude Code](https://claude.com/claude-code).

The skyline at the bottom of the homepage is Indianapolis, where I live.
