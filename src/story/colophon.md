This site uses the font [![](/tool-icons/cal.png)Cal Sans](https://github.com/calcom/font) and is built with [![](/tool-icons/astro.svg)Astro](https://astro.build) and [![](/tool-icons/tailwind.png)Tailwind CSS](https://tailwindcss.com). It’s hosted on [![](/tool-icons/cloudflare.png)Cloudflare Workers](https://workers.cloudflare.com).

Notes are markdown files in a GitHub repo. I draft them in [![](/tool-icons/editor.svg)editor.beckyschmidt.me](https://editor.beckyschmidt.me), a custom markdown editor I built, then publish them through an admin editor built into the site, which creates a pull request that I can merge & rebuild the site. Note reactions are stored in [![](/tool-icons/convex.png)Convex](https://convex.dev), search runs on [![](/tool-icons/fuse.png)Fuse.js](https://www.fusejs.io), and I use [![](/tool-icons/umami.png)Umami](https://umami.is) for analytics.

I started the site in July 2025 and moved it from Netlify to Cloudflare in July 2026. About half the commits since January were made with [![](/tool-icons/claude.png)Claude Code](https://claude.com/claude-code).

The skyline at the bottom of the homepage is Indianapolis, where I live. The image was generated with [![](/tool-icons/chatgpt.svg)ChatGPT](https://chatgpt.com).
