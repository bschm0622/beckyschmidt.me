This site uses the font [![](/tool-icons/cal.png)Cal Sans](https://github.com/calcom/font) and is built with [![](/tool-icons/astro.svg)Astro](https://astro.build) and [![](/tool-icons/tailwind.png)Tailwind CSS](https://tailwindcss.com). It’s hosted on [![](/tool-icons/cloudflare.png)Cloudflare Workers](https://workers.cloudflare.com).

I write notes in [![](/tool-icons/editor.svg)editor.beckyschmidt.me](https://editor.beckyschmidt.me), a custom markdown editor. I publish them through a CMS I built into the site, which saves each note as a markdown file in GitHub. Search runs on [![](/tool-icons/fuse.png)Fuse.js](https://www.fusejs.io).

I develop the site primarily using [![](/tool-icons/claude.png)Claude Code](https://claude.com/claude-code), running in my own fork of [![](/tool-icons/t3code.png)T3 Code](https://t3.codes).

The skyline at the bottom of the homepage is Indianapolis, where I live. The image was generated with [![](/tool-icons/chatgpt.svg)ChatGPT](https://chatgpt.com).

I built my own analytics. A small script on each page sends visits to [![](/tool-icons/cloudflare.png)Cloudflare D1](https://developers.cloudflare.com/d1/), with no cookies and no stored IP addresses. Here's what it counted over the last 30 days.
